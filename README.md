# NUTECH Connect AI 🎓🤖

> **An AI-powered civic assistant that helps NUTECH students access university services and campus information through natural language.**

🔗 **Live Demo:** [NUTECH Connect AI](https://nutech-connect-nu.vercel.app/?utm_source=chatgpt.com)

## 📌 Overview

NUTECH Connect AI addresses a common challenge faced by university students: finding accurate and timely information about campus services, academic procedures, facilities, events, transportation, hostels, and student services.

The platform provides a **centralized conversational interface** where students can ask questions in natural language and receive contextual responses based on **verified NUTECH information**.

It is particularly designed to support:

* 🎓 First-year and newly admitted students
* 🌍 Students from remote or underserved areas
* 🏢 Administrative departments handling repetitive queries
* 🏫 Institutions exploring AI-powered student services

## ✨ Key Features

* 🤖 AI-powered conversational university assistant
* 🏫 Centralized NUTECH information
* 🔎 Context-aware question answering
* 📄 OCR support using Tesseract.js
* 📅 Event and campus-service features
* 📱 Responsive web interface
* 🔐 Architecture designed for verified community access

## 🧠 AI

The system uses **Gemma** as its intelligence layer. Student queries are processed through the application backend and transformed into structured prompts before being answered using contextual reasoning based on verified university data.

## 🛠️ Tech Stack

* **Frontend:** React, TypeScript, Vite
* **Styling:** Tailwind CSS
* **AI:** Gemma
* **OCR:** Tesseract.js
* **Icons:** Lucide React
* **Deployment:** Vercel
